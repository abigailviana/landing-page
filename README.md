# Mi Portafolio Web

Sitio web tipo portafolio personal desarrollado como proyecto de
evaluación de curso 

El sitio presenta información del perfil profesional o académico,
habilidades, herramientas, proyectos y un formulario de contacto. Está
construido con HTML5 semántico y CSS3, con un diseño adaptable a
dispositivos móviles, tablets y computadoras.

## Características

-   Cuatro páginas HTML conectadas mediante un menú de navegación:
    -   **Inicio (`index.html`):** bienvenida, presentación y panel
        lateral.
    -   **Acerca de (`acerca.html`):** perfil, fotografía, habilidades,
        herramientas y áreas de interés.
    -   **Proyectos (`proyectos.html`):** tabla de proyectos con
        tecnologías, fechas y estados.
    -   **Contacto (`contacto.html`):** formulario con distintos
        controles y validaciones HTML5.
-   Hoja de estilos compartida (`style.css`).


## Tecnologías utilizadas

-   HTML5
-   CSS3
